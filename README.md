# Business KPI Dashboard – Customer Churn Analysis

## Project Overview

This project is part of the EdVyro Data Analytics Internship – Task 2: Business KPI Dashboard.

The objective is to transform the cleaned customer churn dataset into a decision-ready dashboard containing important business KPIs, filters, visualizations, and key insights.

## Dataset

The dashboard uses the Customer Churn Sample dataset provided by EdVyro.

The dataset contains customer information including:

* Customer ID
* Tenure
* Contract
* Payment Method
* Monthly Charges
* Churn status

## Key Performance Indicators

### 1. Churn Rate

Churn Rate measures the percentage of customers who have left the service.

Formula:

Churn Rate = Churned Customers / Total Customers × 100

Dashboard value:

46.7%

### 2. Retention Rate

Retention Rate represents the percentage of customers who have remained with the service.

Formula:

Retention Rate = 100% − Churn Rate

Dashboard value:

53.3%

### 3. Revenue at Risk

Revenue at Risk represents the monthly charges associated with customers who have churned.

Dashboard value:

₹409.93 per month

### 4. Average Tenure

Average Tenure represents the average number of months customers have remained with the service.

Dashboard value:

18.8 months

## Dashboard Filters

The dashboard includes filters for:

* Contract
* Tenure
* Payment Method

These filters allow the user to examine customer churn information across different customer groups.

## Visualizations

The dashboard includes:

* Overall Churn Distribution
* Churn Rate by Contract Type
* Customer and churn summaries

The visualizations use clear labels to make the dashboard easier to understand.

## Key Insights

* The dataset contains 15 customers.
* The overall churn rate is 46.7%.
* The retention rate is 53.3%.
* Monthly revenue associated with churned customers is ₹409.93.
* Average customer tenure is 18.8 months.
